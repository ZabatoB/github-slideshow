## 2024-05-23 - [Jekyll Asset Management]
**Learning:** This is a Jekyll site that uses `node_modules` checked into git (likely for serving assets directly). It doesn't seem to have a standard `npm build` process.
**Action:** Be careful not to assume standard Node.js build pipelines. Look for optimizations in Liquid templates (`_includes`, `_layouts`) and frontend assets (JS/CSS).
